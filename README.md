# Solvix NV41 — حصر أصول المباني وإدارة العملاء

ابدأ بقراءة **UPGRADE_NV41_AR.md** للتحديث الحالي، ودليل NV35 لإعداد العملاء والبريد.

دليل المستخدم: **PLATFORM_GUIDE_AR.md**، ونتائج التحقق الحالية: **TEST_RESULTS_NV41.md**.

- سجل الإصدارات ونتائج الفحص ضمن إدارة النظام.
- دليل قابل للبحث يغطي 33 خاصية ويحدث مع كل إصدار.
- سجل نشاط المستخدمين وتسجيل الدخول لمدير النظام داخل المشروع الحالي.

- واجهات عربية وإنجليزية للمباني ورقم المبنى، والصور والموقع وملصقات QR والتقارير.
- إدارة مركزية لعملاء متعددين؛ لكل عميل مشروع Supabase مستقل وحسابات واشتراك وبيانات منفصلة.
- إنشاء حساب مالك العميل وإرسال بيانات الدخول وملخص الاشتراك، مع CC لملخص منفصل دون كلمة المرور.
- تذكيرات اشتراك عبر البريد في مراحل 14 و7 ويوم واحد ثم الانتهاء، مع جدولة مركزية موضحة في الدليل.
- حذف أي حساب بواسطة مدير النظام، بما فيه الحساب الحالي وآخر Admin، مع حفظ تاريخ الأصول بمرجع مؤرشف.
- يتضمن إصلاحات NV34 للصلاحيات والمزامنة والتدقيق وحماية الصور.

- مسارات اعتماد متعددة المراحل بإصدارات وسجل قرارات وإعادة توجيه معللة.
- شاشة مقارنة تعارضات المزامنة ولوحة جودة بيانات الأصول.

- تنبيهات تكرار التسلسلي وأرقام الأصل قبل الحفظ والاستيراد.
- قائمة مهام شخصية تجمع الإرجاع والاعتماد والتعارضات.
- سلة محذوفات للأصول لمدة 30 يوماً مع هوية الحاذف والسبب.

- تحسين تنسيق صفحة الدخول وتوسيطها على الشاشات الواسعة ودعم الشاشات الضيقة.

- العملاء والاشتراكات ضمن قسم النظام؛ أزيل رابط سجل التعديلات مع حفظ التاريخ.

- تحليل تفاعلي برسوم مترابطة وجدول محوري متعدد المستويات والمقاييس وتفاصيل خلايا وحفظ عروض محلي.

## التثبيت والنشر

للتحديث من NV40: استبدل index.html فقط؛ قاعدة البيانات تبقى NV38.

للتحديث من NV39: استبدل index.html فقط. لم تتغير صفحة الدخول أو قواعد العملاء.

للتحديث من NV38: استبدل index.html فقط؛ لا توجد ترقية جديدة لقاعدة البيانات.

للمشروعات الجديدة: شغّل solvix_setup.sql.
للتحديث من NV37: شغّل migrations/038_duplicates_tasks_trash.sql.
للتحديث من NV36: شغّل 037 ثم 038.
للتحديث من NV34: شغّل 035 ثم 036 ثم 037 ثم 038.
للتحديث من إصدار أقدم: شغّل 034 ثم 035 ثم 036 ثم 037 ثم 038 بالترتيب وفق الأدلة.

انشر client-manager كاملاً على المشروع المركزي فقط، وانشر solvix-mail المحدثة. يتطلب البريد أسرار Resend، ويتطلب سجل العملاء مفتاح تشفير خادم. المشروع المستقل لكل عميل يُنشأ ويجهز مسبقاً؛ المنصة لا تنشئ مشروعات Supabase المدفوعة تلقائياً.
